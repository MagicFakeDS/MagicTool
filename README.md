# MagicTool Suite

Набор утилит для быстрой подготовки и обслуживания ПК на Windows.
Исходный код открыт для просмотра. Собирается из исходников.

> ⚠️ Программы требуют прав администратора, работают с дисками,
> драйверами и системными настройками и **могут стереть данные**.
> Используйте на свой риск.

---

## Установка

Скачайте **MagicToolSetup.exe** со страницы
[Releases](../../releases/latest), запустите и отметьте галочками нужные
программы — установщик (~0.6 МБ) сам скачает их с GitHub и проверит
контрольные суммы. Ставит в `Program Files`, создаёт ярлыки, добавляет
запись в «Программы и компоненты» для удаления.

## Что внутри

| Проект | Язык | Назначение |
|--------|------|------------|
| **MagicTool** | C++ | Оконное приложение: создание загрузочной флешки Windows «одной кнопкой» + вкладка быстрых инструментов администратора (20 системных консолей). |
| **ToolboxPC** | C++ | Мастер настройки и оптимизации ПК: анализ системы, установка программ, отключение лишних служб, очистка, отчёты. |
| **WinInstaller** | PowerShell + C# | Сборщик загрузочной флешки: `make-usb.ps1` собирает WinPE-установщик с собственным меню (`PCInstaller`, C#). |

## Сборка

### MagicTool и ToolboxPC (C++)
Нужен MinGW-w64 (WinLibs) в `PATH`:

```bat
winget install BrechtSanders.WinLibs.POSIX.UCRT
```

Затем в папке проекта:

```bat
build.bat
```

Результат — `MagicTool.exe` / `ToolboxPC.exe`.

### PCInstaller (C#)
Нужен .NET SDK:

```bat
cd WinInstaller\src
dotnet build PCInstaller.csproj -c Release
```

## Чего нет в репозитории (и почему)

Чтобы не нарушать чужие лицензии, в репозиторий **намеренно не включены**
сторонние бинарные файлы. Их нужно получить самостоятельно из официальных
источников:

- **Windows ADK + WinPE add-on** — скачивается с сайта Microsoft.
  Образы WinPE распространять нельзя, поэтому их здесь нет.
- **Драйверы** (сеть, Intel RST/VMD и т.п.) — скачиваются с сайтов
  производителей оборудования (Intel, Realtek, Qualcomm, MediaTek и др.).
- **Сторонние программы**, которые ToolboxPC/WinInstaller могут ставить
  или класть на флешку, — скачиваются с официальных сайтов этих программ.
- **Windows ISO** — скачивается с сайта Microsoft пользователем.

Скрипты ожидают эти файлы в соответствующих папках (`WinInstaller\usb\...`,
`WinInstaller\build\...`). Без них собирается только то, на что есть права.

## Проверка целостности

Готовые сборки (если публикуются в разделе **Releases**) сопровождаются
контрольной суммой **SHA-256**. Проверить скачанный файл:

```powershell
Get-FileHash .\MagicTool.exe -Algorithm SHA256
```

Сравните результат со значением на странице релиза. Не совпало — файл
подменён, не запускайте.
