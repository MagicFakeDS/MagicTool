# Загрузочная флешка-установщик Windows со своим меню

Втыкаешь флешку, выбираешь её в меню загрузки (F8 / F11 / F12 / Esc — зависит от материнской платы),
и вместо стандартного установщика Windows открывается своё меню:

1. **Приветствие** — «Windows 10 · 11 TOOLBOX PC», кнопки «Начать установку», «Восстановление», «Выход».
2. **Версия** — Windows 11 или 10, Обычная / Lite, редакция (Домашняя / Pro), светлая или тёмная тема.
3. **Диск** — список накопителей и разделов. Кнопки: Создать, Формат, Удалить, Стереть диск, Весь диск.
4. **Драйверы и программы** — категории слева, карточки с иконками справа. Всё, что нашлось на этом ПК
   (плата, видеокарта, мышь, клавиатура), собрано в категории **«Найдено на этом ПК»** с готовыми галочками.
5. **Настройки Windows** — пауза обновлений, электропитание, удаление мусора и OneDrive, UAC,
   локальная учётная запись (можно сразу указать имя пользователя). Рискованные помечены «!».
6. **Установка** — прогресс в процентах, затем перезагрузка.

После первого входа в Windows само открывается окно **«Настройка TOOLBOX PC»**: оно применяет
настройки, переносит файлы (при переустановке с переносом данных), ставит недостающие драйверы
и по очереди — выбранные программы.

## TOOLBOX PC (программа мастера) на флешке

Программа мастера `ToolboxPC.exe` (анализ, SMART, оптимизация с откатом, ремонт, сеть, активация,
AVZ и RustDesk, отчёт клиенту) лежит на флешке в `Programs\ToolboxPC\` вместе со своей папкой `tools\`.
Ей можно пользоваться тремя способами:

1. **После установки Windows.** В каталоге первая категория — **«Инструменты мастера»**:
   - **TOOLBOX PC 2.0** (галочка стоит заранее) — копируется в `C:\ToolboxPC`, ярлык «TOOLBOX PC»
     на общем Рабочем столе и в «Пуске»;
   - **RustDesk (удалённый доступ)** — ярлык «RustDesk — удалённый доступ» на Рабочем столе
     (`C:\ToolboxPC\tools\rustdesk\rustdesk.exe`, без установки): клиент запускает его, называет ID
     и пароль — и мастер подключается. Галочка по умолчанию снята.
2. **С флешки в работающей Windows** — `TOOLBOXPC.cmd` в корне раздела DATA, меню:
   `1` — запустить TOOLBOX PC прямо с флешки, `2` — скопировать на этот ПК (`C:\ToolboxPC` + ярлыки
   TOOLBOX PC и RustDesk на Рабочем столе, попросит права администратора) и запустить,
   `3` — запустить RustDesk с флешки. Можно и просто открыть `Programs\ToolboxPC\ToolboxPC.exe`.
3. **Перенести вручную** — папка `Programs\ToolboxPC` самодостаточна, её можно скопировать куда угодно.

`make-usb.ps1` при каждой сборке/обновлении флешки (`-UpdateOnly` тоже) берёт **свежий**
`..\ToolboxPC\ToolboxPC.exe` и `..\tools` (без ненужного `avz4.zip`) в `usb\Programs\ToolboxPC`, так что
после пересборки ToolboxPC достаточно `.\make-usb.ps1 -UpdateOnly -DataDrive E:`.

## Восстановление

Кнопка «Восстановление» на первом экране. Слева — найденные установки Windows, справа — действия:

| Действие | Что делает |
|---|---|
| Починить загрузку | заново создаёт загрузчик (`bcdboot`), если Windows перестала запускаться |
| Восстановить системные файлы | DISM RestoreHealth по образу с флешки + SFC; файлы и программы не трогаются |
| Переустановить с переносом данных | новая Windows на тот же диск **без форматирования**: старая уезжает в `Windows.old`, после первого входа Рабочий стол, Документы, Загрузки, Изображения, Видео, Музыка, Избранное и Сохранённые игры сами переносятся в новый профиль |
| Спасти файлы на другой диск | копирует те же папки всех пользователей на флешку или другой диск |
| Ремонт с сохранением программ и паролей | «обновление поверх» от Microsoft — см. ниже |

**Программы, учётные записи и пароли** сохраняет только «обновление поверх», а Microsoft разрешает его
лишь из работающей Windows. Для этого на разделе DATA лежит `REPAIR-WINDOWS.cmd`: загрузи Windows
как обычно, открой флешку и запусти его. Он сам определит Windows 10 или 11 и запустит установщик
Microsoft в режиме обновления. Язык и редакция на флешке должны совпадать, версия — та же или новее.

## Драйверы — автоматически

- **Определение железа.** При запуске установщик смотрит подключённые устройства и плату:
  плата ASUS / MSI / GIGABYTE / ASRock → фирменная утилита, Intel → Intel DSA, видеокарта NVIDIA / AMD →
  их драйвер, Logitech → G HUB (игровые, приёмник Lightspeed) или Options+ (MX, Unifying, Bolt),
  клавиатура / мышь Ardor Gaming → их ПО.
- **«Все недостающие драйверы»** (включено по умолчанию) — после первого входа находит в Центре
  обновления Windows драйверы для всех устройств без драйвера (сеть, Wi-Fi, звук, чипсет, Bluetooth)
  и ставит их. Нужен интернет.
- **Папка `Drivers\`** на флешке — драйверы оттуда встраиваются в Windows прямо при установке
  (удобно для сетевой карты, чтобы интернет был сразу).

**Что уже лежит на флешке** (всё — официальные драйверы из Каталога Центра обновления Microsoft, x64):

| Папка | Что внутри | Зачем |
|---|---|---|
| `Drivers\WinPE\Intel-RST-RAID-8-10gen` | Intel RST 17.11 (iaStorAC) | диск в режиме RAID/RST на Intel 8–10 поколения |
| `Drivers\WinPE\Intel-RST-VMD-11gen` | Intel RST 18.8 (iaStorVD) | VMD на Intel 11 поколения (Tiger Lake) |
| `Drivers\WinPE\Intel-RST-VMD` | Intel RST 20.2 (iaStorVD) | VMD на Intel 12–14 поколения и Core Ultra |
| `Drivers\WinPE\AMD-RAID*` | AMD RAID 9.5 | RAID на платформах AMD |
| `Drivers\Network\LAN-*` | Intel I219, I225/I226; Realtek 1G (8111/8168), 2.5G (8125) | проводной интернет сразу после установки |
| `Drivers\Network\WiFi-*` | Intel Wi-Fi 6/6E, Realtek 8821/8822/8852, MediaTek MT7921/7922, Qualcomm QCA6174 | Wi-Fi сразу после установки |
| `Programs\NVIDIA\NVIDIA_app.exe` | NVIDIA App 11.0.9 | драйвер видеокарты NVIDIA ставится сам после первого входа |

Остальные драйверы (звук, чипсет, Bluetooth, кардридеры…) приезжают через «Все недостающие драйверы».
AMD Adrenalin (amd.com) и утилиты GIGABYTE/ASRock/Ardor (ПО под модель) — положи сам по путям из каталога.
Видеокарты AMD без Adrenalin всё равно получат драйвер через «Все недостающие драйверы».

Своё правило определения добавляется в `catalog.json` полем `detect`. Кнопка **«Устройства ПК»**
на экране программ показывает VID/PID всех USB-устройств — из них и составляется правило:

```json
"detect": ["VID_046D&PID_C53F", "name:ardor", "VID_046D+name:gaming", "board:ASUSTeK", "PCI+VEN_10DE+CC_03"],
"detectLabel": "видеокарта NVIDIA"
```

`name:` — часть названия устройства, `board:` — производитель платы, `+` — всё должно совпасть у одного устройства.

**Ardor Gaming:** универсальной программы у них нет, ПО своё под каждую модель — скачай его на
<https://ardor-gaming.com/drivers> (или на странице товара в DNS) и положи в
`usb\Programs\Ardor\setup.exe` (клавиатура) и `usb\Programs\Ardor\mouse-setup.exe` (мышь).

## Как это устроено

```
Флешка
├─ BOOT (FAT32, 1,2 ГБ) WinPE от Microsoft — грузится и в UEFI, и в старом BIOS, с Secure Boot
└─ DATA (NTFS)
   ├─ installer\         PCInstaller.exe + config.json + catalog.json + assets\
   ├─ win11\             установочные файлы Windows 11 + sources\install.esd (Pro и Домашняя)
   ├─ win10\             то же для Windows 10
   ├─ Drivers\           .inf-драйверы — встраиваются в Windows при установке
   ├─ Programs\          установщики программ, которых нет в winget
   │  └─ ToolboxPC\      программа мастера + tools\ (AVZ, RustDesk)
   ├─ REPAIR-WINDOWS.cmd ремонт «поверх» из работающей Windows
   └─ TOOLBOXPC.cmd      TOOLBOX PC / RustDesk с флешки или копия на этот ПК
```

Одна программа `PCInstaller.exe` (C#, .NET Framework 4.8) работает в двух режимах:
в WinPE это установщик, а в установленной Windows (`--postsetup`) — мастер установки программ.

## Что нужно один раз

1. **.NET SDK** (для сборки программы) — уже стоит.
2. **Windows ADK** (компонент *Deployment Tools*) и **Windows PE add-on** —
   <https://learn.microsoft.com/windows-hardware/get-started/adk-install>.
3. **ISO Windows 11 и/или 10** с сайта Microsoft:
   <https://www.microsoft.com/software-download/windows11>, <https://www.microsoft.com/software-download/windows10>.
4. Флешка **от 16 ГБ** (всё на ней будет стёрто). Обе системы с редакциями Pro и Домашняя занимают ~9 ГБ.

## Сделать флешку

PowerShell **от имени администратора**, в папке `WinInstaller`:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\get-icons.ps1
.\make-usb.ps1 -Iso "D:\Downloads\Win11_Russian_x64.iso", "D:\Downloads\Win10_Russian_x64.iso"
```

Скрипт соберёт программу и WinPE, покажет список USB-дисков, спросит номер флешки и попросит
написать `YES`. Сжатие каждой редакции в ESD — 10–20 минут. Другие редакции:
`-Editions Professional, Core, Education` или все сразу: `-AllEditions`.

Сжатие ESD (по умолчанию) даёт самый маленький образ, но DISM при этом занимает **8+ ГБ памяти**.
Если на компьютере мало памяти или места на диске под файл подкачки — добавь `-Compress max`:
образ выйдет примерно на 15–20 % больше, зато памяти почти не нужно.

**Быстро записывать много флешек.** Сжатие образов — самая долгая часть, его можно сделать один раз:

```powershell
.\make-usb.ps1 -DataOut C:\PCInstallerData -Iso "...\Win11.iso", "...\Win10.iso"   # один раз, 30–60 минут
.\make-usb.ps1 -DataFrom C:\PCInstallerData -BootWim .\build\winpe-components.wim      # каждая флешка — несколько минут
```

**Обновить готовую флешку** после правок каталога, иконок или программы — без пересборки WinPE:

```powershell
.\make-usb.ps1 -UpdateOnly -DataDrive E:
```

### Если на этом ПК не собирается WinPE

Бывает, что DISM не может добавлять компоненты в образ: ошибка 87, а в `C:\Windows\Logs\DISM\dism.log` —
*Failed trying to determine the OS Version*. Причина — сторонний драйвер, из-за которого Windows не
загружает кусты реестра из образа (на этом компьютере так и есть). Тогда WinPE собирается внутри
временной виртуалки Hyper-V — окно не открывается, VM сама соберёт образ, выключится и удалится:

```powershell
.\build-winpe-vm.ps1 -AdkRoot "C:\PCInstallerADK\Windows Kits\10\Assessment and Deployment Kit"
.\make-usb.ps1 -BootWim .\build\winpe-components.wim -AdkRoot "C:\PCInstallerADK\Windows Kits\10\Assessment and Deployment Kit" -Iso ...
```

(`C:\PCInstallerADK` — WinPE и DISM, распакованные вручную: официальный установщик ADK сейчас
падает с ошибкой 0x80091007 из-за несовпадения хэшей на серверах Microsoft.)

**Проверить в Hyper-V**, не трогая флешку: `-VhdOut C:\PCInstallerVM\installer.vhdx` вместо записи
на флешку — получится загрузочный виртуальный диск с той же разметкой.

## Посмотреть интерфейс без флешки

Запусти `build\PCInstaller.exe` в обычной Windows. Вне WinPE он всегда работает в **демо-режиме**:
диски читаются, но ничего не меняется — все команды diskpart/DISM/reg только пишутся в журнал
`%TEMP%\pcinstaller.log`. Окно после установки: `build\PCInstaller.exe --postsetup --demo`.

## Настроить под себя

Всё лежит в `usb\installer\`:

| Что | Где |
|---|---|
| Название, подпись, цвета градиента | `config.json` → `brandName`, `tagline`, `accentColor`, `accentColor2` |
| Логотип | `assets\logo.png` (квадрат) — иначе буква на градиенте |
| Фон | `assets\background.png` и `assets\background-dark.png` (1920×1080 или больше) |
| Иконки программ | `assets\icons\<id>.png` — `get-icons.ps1` заполняет их сам |
| Список программ и правила автоопределения | `catalog.json` |
| Какие приложения Windows удалять | `config.json` → `consumerApps`, `liteExtraApps` |
| Язык/раскладка/часовой пояс | `config.json` → `locale`, `inputLocale`, `timeZone` |

### Программы в каталоге

```json
{ "id": "steam", "name": "Steam", "type": "winget", "winget": "Valve.Steam",
  "description": "…", "site": "https://store.steampowered.com", "default": true }
```

- `winget` — ставится из интернета. ИД пакета проверить командой `winget show --id Valve.Steam`.
- `local` — файл из `Programs\` на флешке, `args` — ключи тихой установки (`/S`, `/VERYSILENT`, `-s`…).
- `drivers` — папка с .inf в `Programs\`, ставится через pnputil.
- `wudrivers` — все недостающие драйверы из Центра обновления Windows.
- `url` — скачать по прямой ссылке и запустить с `args`.
- `portable` — программа без установщика: папка `file` из `Programs\` копируется в `target`
  (например `%SystemDrive%\\ToolboxPC`), ярлык `shortcut` на `exe` внутри папки — на общий Рабочий стол и в «Пуск».
  Так сделаны TOOLBOX PC и RustDesk.

В `local` сейчас записаны **NVIDIA App**, **AMD Adrenalin**, **GIGABYTE Control Center**,
**ASRock APP Shop** и **Ardor Gaming** — их нет в winget. Положи установщики по путям из каталога
(например, `usb\Programs\NVIDIA\NVIDIA_app.exe`). Пока файла нет, карточка серая с надписью
«Нет на флешке» — а драйвер видеокарты всё равно приедет через «Все недостающие драйверы».

## Полезно знать

- **Shift+F10** в установщике открывает командную строку.
- Если установщик **не видит диск** (Intel RST / VMD на ноутбуках, AMD RAID) — положи драйверы
  контроллеров в `Drivers\WinPE\` на флешке. Они загружаются сами при старте флешки и встраиваются
  в устанавливаемую Windows. Для разовых случаев: `Shift+F10` → `drvload путь\драйвер.inf` → «Обновить».
- Флешка рассчитана на **любые компьютеры**: правила автоопределения не привязаны к конкретному ПК,
  поэтому не добавляй в `detect` общие ID вроде «Gaming Keyboard» — они встречаются у многих брендов.
- Журнал установки сохраняется в `C:\ProgramData\ToolboxPC\Logs\` на установленной системе.
- Ключ продукта не вводится: Windows активируется как обычно (цифровая лицензия или ключ позже).
- Если указано имя пользователя, учётная запись создаётся **без пароля** — пароль можно задать после.
- Мастер программ запускается один раз. Доустановить вручную: `C:\ProgramData\ToolboxPC\PCInstaller.exe --postsetup`.
- Windows 10 официально больше не получает обновлений безопасности (с октября 2025) — для новых сборок лучше 11.
